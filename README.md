# Dementia_classification_ML_project
A deep learning pipeline classifying three classes of Dementia: No impairment, Mild impairment and Moderate Impairment 

Binder link: [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/samara-banday/Dementia_classification_ML_project/HEAD)

This project uses machine learning and deep learning techniques to automatically classify medical images and investigate whether patterns in brain scans can be used to distinguish different levels of cognitive impairment.

Project Overview

The aim of this project is to develop an image classification pipeline that can identify dementia-related patterns from brain imaging data. The workflow includes:

- Data loading and organisation
- Image preprocessing
- Exploratory data analysis
- Model development
- Model training and evaluation
- Using transfer learning 
- Performance comparison using accuracy, precision, recall and confusion matrices
